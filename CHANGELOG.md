# Changelog

All notable changes to this project are documented here.
Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), versioning: [SemVer](https://semver.org/).

## [0.1.0] - 2026-11-18
### Added
- Initial multi-file project structure (landing, home, room pages).
- Local accounts: register / login / logout (PBKDF2-hashed passwords).
- Friends system: send, accept, decline, remove; online presence.
- Room invites sent directly to online friends, plus shareable room codes.
- Synchronized YouTube playback (play, pause, seek, change video, drift correction).
- SemVer version badge shown on every page.
